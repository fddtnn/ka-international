# KA International — Luxury Digital Showroom

A premium 3D e-commerce experience for KA International, a high-end home furniture and interior design brand based in Saudi Arabia.

**Live demo:** https://fddtnn.github.io/ka-international/

## Features

- Interactive 3D furniture on every product (drag, zoom, fullscreen, GLB export)
- Real-time product customizer — fabrics, leathers, woods, marbles, metals, sizes, layouts — with live price updates
- "View in Your Room" camera AR mode
- Shop by Room with clickable hotspots and one-tap "Shop the Room"
- Full commerce flow: cart, wishlist, compare, 4-step checkout with Saudi payment methods (UI only)
- Customer account and admin dashboard
- English + Arabic with full RTL
- SEO: JSON-LD product/breadcrumb schema, Open Graph, per-page meta

## Stack

Vite · React 19 · Tailwind CSS 4 · react-three-fiber / drei · Framer Motion · Zustand · React Router 7

## Development

```bash
npm install
npm run dev
```

Payment methods shown at checkout are presentation-only; no payment gateway logic is included.
